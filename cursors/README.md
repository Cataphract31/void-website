# upload/cursors — the Vercel deploy folder

This folder is generated by `npm run build` and committed so the hosted site
stays in sync with the repo (same pattern as THIN ICE's `upload/zinc`).
Do not edit `index.html` by hand — the build overwrites it.

The entire game is the one `index.html` file. There is no build step for
Vercel to run.

## One-time Vercel setup

1. vercel.com → Add New → Project → import the CURSORS repo.
2. **Root Directory**: `upload/cursors`
3. **Framework Preset**: Other. Leave Build Command and Output Directory empty.
4. Deploy. Every `git push` after that updates the site automatically.
