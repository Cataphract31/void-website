# Meme mode art

Drop PNGs here and they are picked up automatically — no code change, one
file at a time is fine. Until a file exists, an emoji placeholder stands in.

| file            | used for                                              |
| --------------- | ----------------------------------------------------- |
| `chad.png`      | roster head for everyone still in (and cashed out)    |
| `snowflake.png` | roster head for eliminated players                    |
| `slap.png`      | optional: replaces the end-of-round emoji slap scene  |

Square images work best for the heads (they render at ~15px in the roster,
so keep the silhouette bold). Toggle the whole layer in the dev panel
("meme mode").
